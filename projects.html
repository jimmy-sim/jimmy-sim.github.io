Presolve for Conic Quadratic Optimization

Undergraduate contributor · September 2026–present

I contribute presolve reductions, test cases, and mathematical documentation to a Rust library for conic quadratic optimization, focusing on variable elimination, infeasibility detection, and solution recovery.

Stock Price Prediction: Comparative Deep Learning Study

Independent project · May–September 2025

Using Python and TensorFlow/Keras, I compared RNN, LSTM, and conditional VAE forecasts for Apple, Amazon, Alphabet, Netflix, and NVIDIA, varying training epochs and batch size. On five years of stock data, these experiments reduced RMSE by up to 62% relative to a vanilla RNN.

Secure Distributed Applications

Research intern, UC Santa Cruz Science Internship Program · June–August 2024

Working with Priyanka Mondal at UC Santa Cruz, I built a Haskell API for secure distributed applications, using monadic design for fault tolerance, safe data flow, and deadlock freedom.
